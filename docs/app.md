# 01 - ESBot

ESBot is a web-based learning assistant for students. Users can create learning sessions for a specific subject and ask an AI questions about topics they want to understand. The AI provides clear and structured explanations and can use the previous messages of the same session as context for followup questions. The conversation is stored so that users can return to an existing learning session and continue where they left off.

## Primary entity and child entity

Primary entity: 
Learning Session - A learning session represents an ongoing learning conversation for a specific topic 

Child entity: 
Message - Each learning session contains multiple messages. A message can either be written by the user or generated by the AI.

Additional entity:
User - A user has an account and can log in to ESBot. Each user can create and own learning sessions.

## External dependency

ESBot uses an external LLM API to generate answers to student questions. LLM is mocked in automated tests because it is external, non deterministic, and may be slow or unavailable.

## Out of scope

The first version of ESBot will not include:
- external identity providers (Keycloak)
- email or SMS verification, multi-factor authentication
- voice input or speech output
- image or document analysis
- a native mobile app
- training or fine-tuning our own AI model
